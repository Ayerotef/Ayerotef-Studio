# Ayerotef-Studio — posters VRChat

Héberge les JPG IPTV pour Image Loading (allowlist `*.github.io`).

## URL de base (Unity)

`https://ayerotef.github.io/Ayerotef-Studio/posters/`

## Setup GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main` / folder: `/ (root)`
3. Push ce repo
4. Dans Unity: **Bake VRCUrls depuis base**

## Noms de fichiers

Même convention que `Assets/_Ayerotef/AyeMenu/IPTVPosters/` :
`{safePlayId}.jpg` (ex. `AyeSmarterPro_Movies_FR_Oceans_8_2018.jpg`)
